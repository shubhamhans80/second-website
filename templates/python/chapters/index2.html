चैप्टर 2: पायथन वैरिएबल्स और डेटा टाइप्स

Python Variables and Data Types in Hindi

पायथन वैरिएबल्स (Variables) क्या हैं?

वैरिएबल्स एक प्रकार के कंटेनर (Containers) होते हैं जिनका उपयोग डेटा या वैल्यूज को कंप्यूटर मेमोरी में स्टोर करने के लिए किया जाता है।

दूसरी भाषाओं (जैसे C++ या Java) की तरह पायथन में वेरिएबल डिक्लेअर करते समय उसका टाइप बताने की जरूरत नहीं होती। पायथन डेटा को देखकर खुद समझ जाता है कि वह किस टाइप का है।

x = 5 # यहाँ x एक इंटीजर वेरिएबल है
name = "Rahul" # यहाँ name एक स्ट्रिंग वेरिएबल है
print(x)
print(name)

पायथन में डेटा टाइप्स (Data Types)

डेटा टाइप यह बताता है कि किसी वेरिएबल में किस प्रकार का डेटा स्टोर किया गया है। पायथन में मुख्य रूप से निम्नलिखित डेटा टाइप्स होते हैं:

  • Numeric Types: इसमें नंबर स्टोर होते हैं। जैसे `int` (पूर्ण संख्या जैसे 10, -5) और `float` (दशमलव वाली संख्या जैसे 10.5)।
  • Text Type (str): इसमें टेक्स्ट या शब्दों को स्टोर किया जाता है। इसे हमेशा सिंगल या डबल कोट्स के अंदर लिखा जाता है (जैसे: "Hello")।
  • Boolean Type (bool): इसमें केवल दो ही वैल्यूज हो सकती हैं — `True` (सही) या `False` (गलत)।
  • Sequence Types: एक से ज्यादा डेटा को एक साथ स्टोर करने के लिए `list`, `tuple` और `range` का इस्तेमाल होता है।

डेटा टाइप्स का उदाहरण

नीचे दिए गए कोड में अलग-अलग डेटा टाइप्स को दिखाया गया है:

age = 25 # int
price = 99.99 # float
is_coding = True # bool
fruits = ["apple", "banana"] # list

# type() फंक्शन से आप किसी भी वेरिएबल का डेटा टाइप जान सकते हैं
print(type(age)) # Output: <class 'int'>
